# Warzone Companion

A **production-grade, mobile-first Call of Duty: Warzone companion app** that automatically and
manually tracks a player's progression — weapon levels, camo challenges, calling cards, seasonal
events, matches and personal objectives — and turns it into a clear, actionable feed.

> **Design principle:** the mobile app *never* talks to a protected third-party game API and *never*
> asks for an Activision password. All third-party access happens server-side behind a replaceable
> provider abstraction, and the app keeps working from manual input and screenshot/OCR sync even
> when no external API is available.

## Architecture at a glance

```
┌────────────────┐      HTTPS/JSON      ┌──────────────────────┐
│  Mobile App    │ ───────────────────► │  Our Backend API     │
│ (Expo / RN)    │ ◄─────────────────── │  (NestJS, port 4100) │
└────────────────┘   JWT + refresh      └──────────┬───────────┘
                                                   │
                        ┌──────────────────────────┼──────────────────────────┐
                        ▼                          ▼                          ▼
                 ┌────────────┐            ┌──────────────┐          ┌──────────────────┐
                 │ PostgreSQL │            │ Redis/BullMQ │          │ Object Storage   │
                 │ (data)     │            │ (job queues) │          │ (S3 / local)     │
                 └────────────┘            └──────┬───────┘          └──────────────────┘
                                                  │
                                                  ▼
                                        ┌──────────────────────┐
                                        │ Background Workers   │
                                        │ sync · ocr · notify  │
                                        └──────────┬───────────┘
                                                   ▼
                                        ┌──────────────────────┐
                                        │ GameDataProvider     │
                                        │ (mock/manual/ocr/…)  │
                                        └──────────────────────┘
```

- **Mobile → our backend only.** The client holds a short-lived access token + rotating refresh token.
- **Provider abstraction.** `GameDataProvider` (getIdentity / getProfile / getMatches / getMatchDetails /
  getWeaponStats / getChallenges / getProgression) is implemented by `MockProvider`, `ManualProvider`,
  `OcrProvider` and a disabled `ActivisionProvider` stub — all registered in a `ProviderRegistry` with
  health monitoring, so a real COD/Activision source can be dropped in later without touching the app.

## Quick start

See **[docs/SETUP.md](docs/SETUP.md)** for full instructions. The short version:

```bash
# 1. Backend
cd backend
npm install
npx prisma migrate deploy
npm run seed            # seeds catalog + FENRIR demo account
npm run build && node dist/src/main.js     # API on http://127.0.0.1:4100/api/v1

# 2. Mobile
cd ../mobile
npm install
npx expo start          # press "a" for Android, "i" for iOS
```

## Feature highlights

- **Dashboard** — next objectives, weapon-level progress, calling-card + event status, and a
  semantic activity feed ("Kilo 141 headshots increased from 72 to 84.").
- **Camos** — overall + per-category completion, camo sets, per-weapon challenge breakdown.
- **Weapons** — search, category & sort filters (level / completion / recent / favourite), favourites.
- **Challenges** — unified camo / calling-card / event challenges with ALL / NEAR / COMPLETED filters.
- **Profile** — identity, overall stats, connected accounts, sync status, notification preferences.
- **Screenshot scanner** — take/choose a screenshot → OCR → confidence scoring → auto-apply ≥95%,
  confirm/edit below.
- **Objectives engine** — auto-detects unfinished objectives and overlapping ones (one action can
  advance a camo, an event and a calling card at once).
- **Non-destructive sync** — incremental, rate-limited, retried, and it never erases data on failure.
